# HW4

## Почему решение не в `.ipynb`?

Решение было перенесено в отдельные `.py` файлы, так как часть заданий использует модуль `multiprocessing`.

На Windows `multiprocessing` работает через механизм `spawn`, из-за чего запуск процессов внутри Jupyter Notebook (`.ipynb`) может приводить к ошибкам создания дочерних процессов и некорректной работе без конструкции:

```python
if __name__ == "__main__":
```

Использование отдельных `.py` файлов обеспечивает:

* корректную работу `multiprocessing` на Windows;
* более стабильный запуск процессов;
* удобное разбиение заданий по темам;
* более чистую структуру проекта.

* `Pool`

* `Queue`

## `threading/`

Содержит следующие 5 задач, связанные с многопоточностью:

* Race Condition
* Synchronization
* Event
* Deadlock
* Singleton (Double-Checked Locking)

## `asyncio/`

Содержит последние 3 задачи, связанные с асинхронным программированием:

* конкурентный запуск корутин;
* `asyncio.wait_for`;
